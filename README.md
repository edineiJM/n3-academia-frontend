# 🏋️ Gestão de Academia - Front-end (Avaliação N3)

Este repositório contém a interface de usuário do projeto de Gestão de Academia, desenvolvido para consumir a API RESTful do nosso back-end.

## 🛠️ Tecnologias Utilizadas
* **React** com **Vite**
* **JavaScript**
* **GitHub Actions** (Pipeline de CI/CD para validação de build)

## 🚀 Como rodar o projeto localmente

**⚠️ Importante:** Certifique-se de que o Back-end da aplicação já está rodando localmente na porta `3000` antes de iniciar o Front-end.
